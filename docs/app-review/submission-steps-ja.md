# PaperStory：iPhoneとMacの両方を提出する手順

1. Xcodeで `paperstory` スキームを選ぶ。iPhone版はiPhone実機／シミュレータ、Mac版はMy Macを実行先に選ぶ。
2. それぞれの実機で起動・作品選択・ドラッグ・切断・表示切り替え・戻る・保存と再開を確認する。
3. App Store ConnectのPaperStoryにiOS版を残したまま、必要なら「プラットフォームを追加」でmacOSを追加する。
4. 各プラットフォーム向けにArchiveし、署名済みビルドをアップロードする。
5. iOS版にはiPhone実機の録画・スクリーンショット、Mac版にはMac実機の録画・スクリーンショットを添付する。
6. 「サインインが必要です」はオフ。`review-notes-en.txt` を審査メモに貼り付け、実際に録画を添付してから添付済みの記述を追加する。
7. Appのプライバシーは、iPhone版にAdMob / UMPが含まれることを踏まえて回答する。Mac版は広告なし。Webのサポート・プライバシー説明にもこの区別を反映する。
8. 各プラットフォームのバージョンを審査へ提出する。iPhone版を取り下げる操作は行わない。

署名・アップロード・審査提出・Webページ更新はコード変更だけでは完了しない。
